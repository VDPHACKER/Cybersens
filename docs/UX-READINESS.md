# Checklist UX avant mise en ligne

## 1. Première impression

- [ ] Le site explique clairement son objectif en moins de quelques secondes.
- [ ] L’utilisateur comprend immédiatement à quoi sert CyberSens.
- [ ] La page d’accueil donne une première voie d’action claire.
- [ ] Le parcours d’inscription est simple et rassurant.

## 2. Parcours d’apprentissage

- [ ] Les modules sont clairement présentés avec niveau, durée et progression.
- [ ] Le bouton “continuer” est visible et évident.
- [ ] La progression est compréhensible et visible dans le parcours.
- [ ] Les quiz et examens donnent un retour immédiatement lisible.

## 3. Feedback et compréhension

- [ ] Les erreurs de formulaire sont explicites.
- [ ] Les messages de succès sont visibles et rassurants.
- [ ] Les écrans de chargement existent quand c’est nécessaire.
- [ ] Les états “vide”, “erreur”, “réussite” sont traités.

## 4. Mobile et accessibilité

- [ ] Le site est testable et lisible sur mobile.
- [ ] Les boutons sont assez grands pour un usage tactile.
- [ ] Le contraste est suffisant.
- [ ] La navigation clavier reste fonctionnelle.
- [ ] Le focus reste visible lors du parcours clavier.

## 5. Motivation et engagement

- [ ] Les points, niveaux ou récompenses sont visibles.
- [ ] La progression donne un sentiment d’avancement.
- [ ] La prochaine action est toujours indiquée.
- [ ] Les recommandations de cours restent utiles et non intrusives.

## 6. Chemin de validation utilisateur

Tester avec un profil réel :

- [ ] inscrivez-vous
- [ ] connectez-vous
- [ ] trouvez un module
- [ ] démarrez une leçon
- [ ] passez un quiz
- [ ] regardez votre progression
- [ ] récupérez un certificat
- [ ] revenez sur la plateforme plus tard

## 7. Validation finale

- [ ] Le parcours principal n’a pas de blocage.
- [ ] La plateforme semble claire même sans explication technique.
- [ ] L’utilisateur sait quoi faire ensuite.
- [ ] Le produit inspire confiance et donne envie de poursuivre.

## 8. Critère de sortie

Le produit est prêt si :

- l’utilisateur peut accomplir le parcours principal sans aide,
- la progression est compréhensible,
- le site reste confortable sur mobile,
- les messages et retours sont clairs,
- l’expérience donne un sentiment de progression et de confiance.
